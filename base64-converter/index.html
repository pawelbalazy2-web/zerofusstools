What Base64 is used for

Base64 encodes binary or text data into a safe ASCII string — used for embedding images directly in HTML/CSS, sending data through APIs, and storing data in text formats like JSON or XML where raw binary isn't allowed.

Is Base64 encryption?

No — it's encoding, not encryption. Anyone can easily decode a Base64 string back to its original form, so it doesn't protect sensitive data.
