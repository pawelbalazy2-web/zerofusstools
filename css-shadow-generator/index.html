How box-shadow works

The CSS box-shadow property takes four key values: horizontal and vertical offset (where the shadow falls), blur (how soft the edges are), and spread (how far the shadow extends beyond the element). Subtle, low-opacity shadows create a modern sense of depth popular in current UI design.
