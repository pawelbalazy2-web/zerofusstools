Memory Game

Find all the pairs in as few moves as possible.

Moves: 0

How to play

The board has eight pairs of hidden symbols, shuffled randomly. Each turn, flip two cards — if they match, they stay revealed; if not, they flip back after a moment. The game ends when you've found all eight pairs.

The key to a good score is remembering the position of cards you've already seen, even ones you didn't match — that turns future moves from guesses into calculated picks.
