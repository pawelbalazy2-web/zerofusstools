A brief history of Morse code

Morse code was developed in the 1830s-40s for telegraph communication — each letter and number is represented by a sequence of short and long signals (dots and dashes). Though telegraphs are long obsolete, Morse code is still used in amateur radio, aviation, and emergency signaling (SOS being the most recognizable Morse signal).
