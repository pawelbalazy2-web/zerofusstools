What makes a password strong

Password strength comes down to two main factors: length and character variety. Every extra character exponentially increases the number of possible combinations an attacker would need to try. A 16-character password mixing upper and lowercase letters, numbers, and symbols is practically uncrackable by brute force with current computing power.

Why this tool is safe to use

The password you type is analyzed entirely in your browser — it's never sent to a server or stored. You can verify this yourself by checking the page's source code.
